# AGENTS

This repository is a Jekyll site published at https://blog.tenucci.it.

Machine-local notes and drafts **must not** be committed. Keep them under the `local/` directory at the repository root.

**Before doing substantive work in this repo**, read **`local/AGENTS.md`** if it exists on disk. That file is the canonical extended agent brief (stack, scope, Git, editorial pointers). If it is missing, rely on this file and the public tree only.

When helping with the site, use the public tree (`_layouts/`, `_posts/`, `_config.yml`, etc.). For task-specific context, also read other files under `local/` when relevant; if `local/` is empty or missing, continue without it.
